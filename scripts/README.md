# Scripts Folder

This folder contains utility and migration scripts used during development.

## Files

### Visix Integration (Experimental)
- `add_visix_comp.cjs` - Script to add Visix component
- `add_visix_comp2.cjs` - Second version
- `add_visix_comp3.cjs` - Third version
- `remove_visix_comp.cjs` - Script to remove Visix component

### Update Scripts
- `update_app.cjs` - App.tsx update script
- `update_list_view.js` - ListView update script
- `update_package.cjs` - package.json update script
- `update_package.js` - Alternative version

## Note

These scripts were used during development for testing Microsoft Graph/Visix integration.
**They are not required for the application to function.**

If no longer needed, they can be deleted.
